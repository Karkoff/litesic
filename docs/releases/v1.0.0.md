**LiteSic 1.0 — versão final e estável.** A release `v1.0.0` traz a interface completa com player, equalizador e playlist, em versões para Windows x64 e x86.

## Escolha seu download

| Arquivo | Uso |
| --- | --- |
| `LiteSic-v1.0.0-x64.zip` | Windows de 64 bits, com preferências no perfil do Windows. |
| `LiteSic-v1.0.0-x86.zip` | Windows de 32 bits, com preferências no perfil do Windows. |
| `LiteSic-v1.0.0-portable-x64.zip` | Portátil para Windows de 64 bits. |
| `LiteSic-v1.0.0-portable-x86.zip` | Portátil para Windows de 32 bits. |

Extraia o ZIP inteiro e abra **LiteSic.exe**. Todos os pacotes incluem os **18 idiomas**, ajuda e licenças. Não é necessário instalar runtimes ou ferramentas de desenvolvimento.

Na edição portátil, o duplo clique já ativa o modo portátil. Preferências, favoritos e sessão ficam em `data/`, junto ao executável. Mantenha `resources/portable.flag` no pacote. Na edição padrão, os dados ficam em `%LOCALAPPDATA%\LiteSic`.

## Recursos

- MP3, WAV, FLAC e OGG Vorbis; arquivos, pastas e arraste do Explorer.
- Playlist com pesquisa, favoritos, reordenação e importação/exportação M3U/M3U8.
- Equalizador de 10 bandas, pré-amplificação e presets.
- Espectro de áudio e osciloscópio; player compacto com visualizador ocultável.
- 36 temas, escala ajustável, painéis que se encaixam e 18 idiomas.
- Atalhos de teclado e multimídia, restauração da sessão e recuperação da saída de áudio após perda do dispositivo.

Gratuito, sem anúncios, conta ou streaming. Nenhuma música acompanha o aplicativo.

## Compatibilidade e observações

Verificado no **Windows 11**, em x64 e x86. O alvo da distribuição tradicional é Windows 7–11; a validação prática no Windows 7/8/8.1/10 ainda está pendente.

As playlists guardam caminhos absolutos das músicas. Se mover os arquivos de áudio para outra pasta ou unidade, adicione-os novamente ou atualize a lista. Extraia os pacotes portáteis em uma pasta gravável.

`SHA256SUMS.txt` contém os hashes dos quatro ZIPs. Esta release é a distribuição desktop pelo GitHub; a edição Microsoft Store continua em preparação.

## English

Extract the complete x64 or x86 ZIP and run **LiteSic.exe**. All packages include 18 languages, help and license notices. Portable packages automatically store settings and playlists in `data/` next to the executable; keep `resources/portable.flag`. Standard packages use the Windows user profile. No extra runtime or development tools are required. Tested on Windows 11; practical validation on Windows 7–10 remains pending. Playlists use absolute media paths, so moved music may need to be added again. ZIP checksums are provided in `SHA256SUMS.txt`.
