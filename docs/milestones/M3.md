# M3 — Player principal

**Depende de:** M2
**Checkpoint visual:** 🖥️ sim — todos os controles clássicos do player
Winamp funcionando com um arquivo tocando.

## Objetivo

Completar a interface do player principal: display de tempo, título
rolando, informações técnicas do arquivo, seek, volume, balanço,
navegação. Ainda sem lista real (M5) — navegação anterior/próxima opera
sobre um estado interno mínimo até a lista existir.

## Tarefas

- [ ] **M3-T1 — Display LCD de tempo**
  - **Arquivos:** `src/mainwnd.cpp`, `src/skin.h/.cpp` (se já fizer sentido
    extrair desenho de dígitos como utilitário reaproveitável).
  - **O que fazer:**
    - Desenhar dígitos estilo LCD (pode ser bitmap font simples desenhado
      via GDI `BitBlt` de um sprite sheet placeholder, ou desenho vetorial
      de segmentos — decidir pela abordagem mais simples de manter).
    - Formato `MM:SS`; recalcular a cada tick do timer (M2-T4).
    - `WM_LBUTTONDOWN` na área do LCD alterna um flag `showRemaining`;
      quando ativo, mostra `-(duração - posição)` em vez do tempo decorrido.
  - **Testes:** teste unitário puro para a função de formatação
    `FormatTime(double seconds, bool remaining, double duration) -> wstring`
    (lógica sem GDI, fácil de isolar e testar com vários valores, incluindo
    bordas como 0s, >99:59, negativo por arredondamento).
  - **Pronto quando:** teste de formatação passa; clique alterna
    decorrido/restante visualmente.

- [ ] **M3-T2 — Título rolando (scrolling text)**
  - **Arquivos:** `src/mainwnd.cpp`.
  - **O que fazer:**
    - Extrair nome de exibição do arquivo (nome do arquivo por enquanto;
      tags reais entram no M5-T6) e desenhar num retângulo fixo.
    - Se o texto for maior que a área, rolar horizontalmente com timer
      (reaproveitar ou criar um `SetTimer` dedicado), com pausa nas pontas
      antes de inverter/repetir (comportamento clássico Winamp: rola,
      pausa, volta ao início ou inverte — escolher um e documentar no
      código só se a escolha não for óbvia).
    - Usar `GetTextExtentPoint32W` para medir e decidir se precisa rolar.
  - **Testes:** teste unitário da lógica de cálculo de offset de scroll
    dado (largura do texto, largura da área, tempo decorrido) — separar
    essa matemática de qualquer chamada GDI para poder testar.
  - **Pronto quando:** título curto fica estático e centralizado/alinhado;
    título longo rola suavemente.

- [ ] **M3-T3 — Indicador kbps/kHz/estéreo**
  - **Arquivos:** `src/audio.h/.cpp`, `src/mainwnd.cpp`.
  - **O que fazer:**
    - Expor em `audio.h`: `int Audio_GetSampleRate(); int Audio_GetChannels();
      int Audio_GetBitrateKbps();` — sample rate e canais vêm direto do
      decoder (`ma_sound`/`ma_data_source` expõe isso); bitrate para
      formatos VBR pode não ter um valor único exato — usar o bitrate
      médio informado pelo decoder quando disponível, ou calcular a partir
      de `tamanho_arquivo_bits / duração` como aproximação, documentando a
      limitação.
    - Desenhar como texto pequeno próximo ao LCD.
  - **Testes:** teste unitário do cálculo de bitrate aproximado (dado
    tamanho em bytes e duração em segundos).
  - **Pronto quando:** valores exibidos batem com o que outro player
    (referência externa) mostra para o mesmo arquivo, dentro de tolerância
    razoável para VBR.

- [ ] **M3-T4 — Barra de busca (seek)**
  - **Arquivos:** `src/mainwnd.cpp`, `src/audio.h/.cpp`.
  - **O que fazer:**
    - `void Audio_SeekSeconds(double seconds);` em `audio.cpp` usando
      `ma_sound_seek_to_pcm_frame` convertendo segundos→frames pelo sample
      rate.
    - Slider desenhado (thumb arrastável) sincronizado com a posição via
      timer; ao arrastar manualmente, suspender a sincronização automática
      até soltar o botão do mouse (`WM_LBUTTONUP`), senão o thumb "briga"
      com o usuário.
  - **Testes:** teste unitário da conversão segundos↔posição do slider
    (mapeamento linear, incluindo bordas 0 e duração total).
  - **Pronto quando:** arrastar a barra pula a posição da música
    corretamente; a barra acompanha a reprodução quando não está sendo
    arrastada.

- [ ] **M3-T5 — Volume e balanço**
  - **Arquivos:** `src/audio.h/.cpp`, `src/mainwnd.cpp`.
  - **O que fazer:**
    - `void Audio_SetVolume(float v);` (0.0–1.0) via `ma_sound_set_volume`
      ou `ma_engine_set_volume`.
    - Balanço: `void Audio_SetPan(float p);` (-1.0 a 1.0) via
      `ma_sound_set_pan`.
    - Dois sliders verticais/horizontais na UI, com desenho e hit-test
      parecidos com o slider de seek (candidato a função utilitária
      compartilhada — extrair se o código começar a duplicar).
  - **Testes:** teste unitário do mapeamento pixel↔valor dos sliders.
  - **Pronto quando:** volume audivelmente correto de 0 a 100%; balanço
    move o som entre os canais esquerdo/direito.

- [ ] **M3-T6 — Anterior/próxima, aleatório/repetir**
  - **Arquivos:** `src/mainwnd.cpp`, `src/playlist.h` (interface mínima
    ainda, implementação completa só no M5).
  - **O que fazer:**
    - Criar em `playlist.h` uma interface mínima só com o necessário para
      o player operar sobre "a faixa atual" (ex.: `int GetCurrentIndex();
      bool Next(); bool Previous();`), com uma implementação provisória de
      lista de 1 item (o arquivo aberto via M2-T4). Será substituída pela
      implementação real no M5, sem quebrar quem já usa a interface.
    - Botões anterior/próxima desenhados e ligados a essa interface.
    - Toggle de aleatório/repetir: só guardar o estado (bool) por enquanto
      e mostrar visualmente ligado/desligado; efeito real na ordem de
      reprodução só faz sentido com lista real (M5).
  - **Testes:** teste unitário da interface mínima de playlist (lista de 1
    item: `Next()`/`Previous()` não saem dos limites).
  - **Pronto quando:** botões existem, respondem visualmente, e a interface
    está pronta para ser trocada pela implementação real no M5 sem alterar
    `mainwnd.cpp`.

## Checkpoint da milestone

- [ ] LCD: clique alterna decorrido/restante.
- [ ] Título rola quando maior que a área disponível.
- [ ] kbps/kHz/estéreo exibidos corretamente.
- [ ] Seek funciona arrastando a barra.
- [ ] Volume e balanço funcionam audivelmente.
- [ ] Botões anterior/próxima/aleatório/repetir existem e respondem.
- [ ] Validado manualmente pelo usuário antes de seguir para M4.
