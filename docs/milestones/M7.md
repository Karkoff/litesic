# M7 — Integração das janelas

**Depende de:** M6
**Checkpoint visual:** 🖥️ sim — player, EQ e lista se comportam como um
conjunto único, estilo Winamp.

## Objetivo

Fazer as três janelas (player, EQ, lista) se encaixarem (snap) e se
moverem juntas, com botões para mostrar/ocultar EQ e lista.

Ajuste pontual autorizado após M6: EQ e playlist encaixam no player, usam
âncoras fixas e acompanham seu movimento/escala. Ver [WINDOW-SNAP](../WINDOW-SNAP-2026-10-11.md).
Isso não encerra o escopo completo desta milestone (encaixe entre quaisquer
janelas e propagação transitiva ainda não foram implementados).

## Tarefas

- [ ] **M7-T1 — Extrair base comum de janela (skin.h/.cpp)**
  - **Arquivos:** `src/skin.h`, `src/skin.cpp`, refatoração de
    `mainwnd.cpp`, `eqwnd.cpp`, `plwnd.cpp`.
  - **O que fazer:**
    - Se M1–M6 já deixaram duplicação entre as três janelas (registro de
      classe, tratamento de título arrastável, botões fechar/hover,
      double buffering), extrair para `skin.cpp` funções/estruturas
      reaproveitadas pelas três.
    - Não forçar abstração além do que já existe de fato duplicado — só
      extrair o que está genuinamente repetido.
  - **Testes:** os testes unitários já existentes (formatação, sliders,
    etc.) continuam passando após a refatoração — rodar `make test`
    antes de commitar.
  - **Pronto quando:** as três janelas compilam e funcionam como antes,
    usando a base comum onde fizer sentido.

- [ ] **M7-T2 — Encaixe (snap) entre janelas**
  - **Arquivos:** `src/skin.cpp` (ou `mainwnd.cpp`/`eqwnd.cpp`/`plwnd.cpp`
    se a lógica de snap ficar específica por par de janelas).
  - **O que fazer:**
    - Ao arrastar qualquer uma das três janelas (`WM_MOVING` ou tratamento
      customizado do arraste do título), detectar proximidade das bordas
      com as outras janelas (threshold em pixels, ex. 10px) e ajustar a
      posição para encostar exatamente (snap).
    - Guardar o relacionamento de encaixe (quem está grudado em quem, e
      de que lado) para a M7-T3 usar.
  - **Testes:** teste unitário da função de cálculo de snap (dado
    retângulo da janela arrastada e retângulo da janela alvo, retorna a
    posição ajustada quando dentro do threshold, ou a posição original
    quando fora) — isolar essa matemática de `WM_MOVING` para testar sem
    janela real.
  - **Pronto quando:** teste de snap passa; arrastar uma janela perto de
    outra faz encaixar visualmente.

- [ ] **M7-T3 — Mover em conjunto**
  - **Arquivos:** mesmo de M7-T2.
  - **O que fazer:**
    - Usando o relacionamento de encaixe guardado em M7-T2, quando o
      player for movido, mover junto qualquer janela grudada nele (e
      transitivamente, se lista estiver grudada no EQ que está grudado no
      player).
  - **Testes:** teste unitário da propagação de movimento no grafo de
    encaixe (dado um deslocamento no player, quais janelas devem mover e
    para onde).
  - **Pronto quando:** mover o player arrasta EQ/lista junto quando
    encaixados; desencaixar (arrastar para longe) separa normalmente.

- [ ] **M7-T4 — Botões EQ/PL mostram/ocultam**
  - **Arquivos:** `src/mainwnd.cpp`.
  - **O que fazer:**
    - Botões no player (placeholders visuais até este ponto) alternam
      `ShowWindow(SW_SHOW/SW_HIDE)` das janelas de EQ e lista.
    - Ao mostrar pela primeira vez (ou após ter sido movida manualmente),
      posicionar encaixada no player por padrão.
  - **Testes:** manual.
  - **Pronto quando:** botões mostram/ocultam corretamente, e a primeira
    exibição aparece encaixada no player.

## Checkpoint da milestone

- [ ] Arrastar uma janela perto de outra encaixa (snap) visualmente.
- [ ] Mover o player arrasta as janelas encaixadas junto.
- [ ] Botões EQ/PL mostram/ocultam as respectivas janelas.
- [ ] Desencaixar (arrastar para longe) funciona normalmente.
- [ ] Validado manualmente pelo usuário antes de seguir para M8.
