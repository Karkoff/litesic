## Tarefas

- [ ] **M8-T1 — Atalhos de teclado estilo Winamp**
  - **Arquivos:** `src/app.cpp` ou `src/mainwnd.cpp` (tratamento de
    aceleradores).
  - **O que fazer:**
    - Tabela de aceleradores (`CreateAcceleratorTable` ou tratamento
      manual de `WM_KEYDOWN` no loop de mensagens) para: `Z` anterior,
      `X` play, `C` pause, `V` stop, `B` próxima, setas esquerda/direita
      (seek relativo), `L` abrir arquivo, `Ctrl+D` modo aleatório (ajustar
      teclas exatas conforme convenção clássica do Winamp, documentando
      no código se divergir).
  - **Testes:** nenhum automatizado (entrada de teclado). Validar manual.
  - **Pronto quando:** cada atalho dispara a ação correspondente com o
    foco em qualquer uma das três janelas.

- [ ] **M8-T2 — Teclas de mídia do teclado**
  - **Arquivos:** `src/app.cpp`.
  - **O que fazer:**
    - Tratar `WM_APPCOMMAND` para `APPCOMMAND_MEDIA_PLAY_PAUSE`,
      `APPCOMMAND_MEDIA_STOP`, `APPCOMMAND_MEDIA_NEXTTRACK`,
      `APPCOMMAND_MEDIA_PREVIOUSTRACK` (teclado multimídia dispara essas
      mensagens automaticamente para a janela em foco/ativa).
  - **Testes:** manual (depende de teclado físico com teclas de mídia, ou
    simulação via `SendMessage` manual em teste exploratório).
  - **Pronto quando:** teclas de mídia do teclado controlam o player.

- [ ] **M8-T3 — Sempre no topo e zoom da interface**
  - **Arquivos:** `src/mainwnd.cpp`.
  - **Já feito adiantado (ver "Pós-checkpoint" em `docs/milestones/M3.md`):**
    a parte de DPI/zoom foi implementada durante correções pós-checkpoint
    do M3, porque a janela renderizava cortada numa tela 4K. Já existem:
    `SetProcessDpiAwarenessContext` (Per-Monitor V2) em `app.cpp`;
    `GetDpiScaleFactor`/`MainWnd_DPIScale`/`MainWnd_DPIUnscale` em
    `mainwnd.cpp` (escala aplicada tanto ao desenho quanto ao hit-test do
    mouse, e `ApplyInterfaceScale()` redimensiona a janela de verdade via
    `SetWindowPos`); e um menu de contexto "Aparência > Escala da
    interface" (Automática/80–150%) como zoom manual do usuário — a persistência `ScalePercent` já existe em `ui_theme.cpp` e deve ser preservada.
  - **O que falta:**
    - Toggle "sempre no topo": `SetWindowPos(hwnd, HWND_TOPMOST/HWND_NOTOPMOST, ...)`.
    - Decidir se o menu de contexto improvisado vira a UI definitiva de
      escala ou se é substituído por uma tela de configurações.
  - **Testes:** se houver função de conversão de coordenadas
    lógicas→físicas pelo fator de escala, testar isoladamente.
  - **Pronto quando:** "sempre no topo" funciona; zoom aumenta a interface
    sem quebrar hit-test dos controles.

- [ ] **M8-T4 — Instância única**
  - **Arquivos:** `src/app.cpp`.
  - **O que fazer:**
    - `CreateMutexW` com nome único no início do `wWinMain`; se
      `GetLastError() == ERROR_ALREADY_EXISTS`, encontrar a janela da
      instância existente (`FindWindowW`) e repassar os argumentos de
      linha de comando (arquivo(s) a abrir) via `WM_COPYDATA`, depois
      encerrar a nova instância.
    - Instância existente trata `WM_COPYDATA` adicionando o(s) arquivo(s)
      recebido(s) à lista e trazendo a janela para frente
      (`SetForegroundWindow`).
  - **Testes:** manual — abrir dois arquivos separadamente pelo Explorer
    deve resultar em uma única instância com ambos na lista.
  - **Pronto quando:** comportamento acima confirmado manualmente.

- [ ] **M8-T5 — Configurações em INI e persistência da lista**
  - **Arquivos:** `src/config.h`, `src/config.cpp`.
  - **O que fazer:**
    - Consolidar modos instalado/portátil sem caminhos absolutos: instalado
      usa diretório de dados do usuário (a implementação atual usa LOCALAPPDATA;
      documentar decisão/migração do plano APPDATA). Portátil usa `data/`
      relativa ao executável e funciona sem instalação. O plano antigo de INI
      ao lado do exe fica substituído pelo contrato M10 de somente exe na raiz;
      definir sinalização explícita do modo e migração compatível de perfis.
    - Salvar/ler: posição das janelas, volume, balanço, estado do EQ
      (bandas + pré-amp + preset ativo), aleatório/repetir, sempre no
      topo, zoom, e a playlist atual (pode reaproveitar o formato M3U do
      M5-T5 para isso). Para zoom, incluir `g_userScalePercent`
      (`src/mainwnd.cpp`) — a escolha de escala já persiste; reutilizar o mecanismo existente.
    - Usar `GetPrivateProfileStringW`/`WritePrivateProfileStringW` (ou
      parser próprio, se preferir não depender das APIs INI do Windows —
      decidir e documentar a escolha) para ler/escrever.
    - Salvar ao fechar (`WM_DESTROY` do player, antes de
      `PostQuitMessage`); carregar na inicialização, antes de mostrar as
      janelas.
  - **Testes:** `tests/test_config.cpp` — round-trip de escrita/leitura do
    INI para cada campo persistido (incluindo valores de borda: strings
    com caracteres Unicode em caminhos de arquivo, floats de gain
    negativos).
  - **Pronto quando:** testes de round-trip do INI passam; fechar e abrir
    o app restaura volume, EQ, lista e posição das janelas.
