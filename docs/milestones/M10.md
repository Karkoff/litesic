# M10 — Distribuição

**Depende de:** M9
**Checkpoint visual:** build final — entregável para o usuário testar fora
do ambiente de desenvolvimento.

## Objetivo

Empacotar o LiteSic para distribuição: builds 32/64 bits reproduzíveis,
zip portátil, e opcionalmente um instalador.

## Tarefas

- [ ] **M10-T1 — Build Release reproduzível**
  - **Arquivos:** `Makefile` (ajustes finais se necessário), `README.md`.
  - **O que fazer:**
    - Confirmar que `make` (64 bits) e `make ARCH=32` a partir de um
      checkout limpo (`git clean` num diretório separado, ou `make clean
      && make`) geram exatamente os binários esperados, sem passos manuais
      extras.
    - Documentar no `README.md` o comando exato de release para cada
      arquitetura.
  - **Testes:** rodar o build limpo duas vezes e comparar hash dos
    binários (deve ser idêntico, ou as diferenças explicadas — ex.
    timestamp embutido pelo linker).
  - **Pronto quando:** processo de build documentado e reproduzível.

- [ ] **M10-T2 — Empacotar .zip portátil**
  - **Arquivos:** script de empacotamento (ex. `scripts/package.sh` ou
    alvo `make dist` no `Makefile`).
  - **O que fazer:**
    - Gerar `LiteSic-win64.zip` e `LiteSic-win32.zip`, cada um contendo o
      `.exe` correspondente e um `LiteSic.ini` vazio ao lado (ativa modo
      portátil, conforme M8-T5).
    - Incluir `README.md`/licença de terceiros (miniaudio, stb_vorbis) no
      zip.
  - **Testes:** extrair o zip numa pasta limpa e confirmar que o app abre
    e salva configurações no próprio `LiteSic.ini` (modo portátil), não
    em `%APPDATA%`.
  - **Pronto quando:** os dois zips gerados e validados manualmente.

- [ ] **M10-T3 — Instalador com Inno Setup (opcional)**
  - **Arquivos:** `installer/LiteSic.iss` (ou similar).
  - **O que fazer:**
    - Script Inno Setup gerando instalador para 32 e 64 bits (ou um
      instalador único que escolhe a arquitetura), sem exigir
      dependências extras.
    - Testar o instalador rodando no Windows 7 (mesma VM do M9).
  - **Testes:** instalar, abrir o app instalado, desinstalar, confirmar
    que nada fica órfão (registro, arquivos) além do esperado.
  - **Pronto quando:** instalador funcional testado na VM Win7.

## Checkpoint da milestone

- [ ] Build Release 64 e 32 bits reproduzível e documentado.
- [ ] `LiteSic-win64.zip` e `LiteSic-win32.zip` gerados e validados.
- [ ] Modo portátil confirmado nos zips.
- [ ] (Opcional) Instalador Inno Setup funcional testado no Win7.
